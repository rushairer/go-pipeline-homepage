# Что нового в v2.2.4

Патч-релиз, сосредоточенный на аккуратных оптимизациях производительности и исправлении документации.

- Повторное использование batch-контейнеров на синхронных путях
- Измерение времени flush только при установленном `MetricsHook`
- Уточнение роли `MaxConcurrentFlushes` как механизма жесткого backpressure
- Выравнивание документации по `done`, `ErrorChan` и воспроизводимым benchmark-командам
